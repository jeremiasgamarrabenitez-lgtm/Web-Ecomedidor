SIMULADOR DE CARGAS ELECTRICAS DOMICILIARIAS - V2

Incluye:
- Arduino UNO: 3 pulsadores + 3 LEDs.
- Deteccion de enchufado/desenchufado.
- Web Serial.
- Potencia instantanea.
- Energia acumulada total.
- Energia acumulada individual por aparato.
- Tiempo individual de uso.
- Costo individual y total.
- Tarifa configurable.
- Reinicio de nueva simulacion.
- Guia de montaje fisico.

Potencias:
TV 80 W
COCINA 1800 W
CARGADOR 10 W

Para ejecutar:
1. Cargar arduino/simulador_cargas.ino.
2. Conectar Arduino.
3. Abrir terminal en app.
4. Ejecutar: python -m http.server 8000
5. Abrir http://localhost:8000
6. Conectar Arduino desde la aplicacion.

NO conectar 110/220 V.
